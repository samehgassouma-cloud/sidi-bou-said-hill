# سيدي بو سعيد — Sidi Bou Saïd Hill

أعمال الأستاذة سماح قسومة لتثمين قرية سيدي بو سعيد (تراث عالمي لليونسكو، ملف 1769) بالذكاء الاصطناعي.

## الأعمال

- [`amal-1`](amal-1/) — العمل الأول: منصة الانزلاقات الأرضية (توعية + أداة جيوتقنية ثلاثية الأبعاد)
- [`amal-2`](amal-2/) — العمل الثاني: رفيق سيدي بوسعيد (خريطة تونس، مخطّط القرية، ديوراما ثلاثي الأبعاد، محادثة الدليل، حجز مقهى، شاشة مطبخ)
- [`amal-3`](amal-3/) — العمل الثالث

كل دوسي فيه ملف `index.html` متاع العمل.
